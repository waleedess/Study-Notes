# CSS Syntax 

`SELECTOR {` => ex. body *-selected HTML tag-*
	`PROPERTY: VALUE` => ex. color: navy
`}`

# Simple Selectors

- Have 4 Types:
	1. Element
	2. Class
	3. ID
	4. Inline   

### Element Selector 

`<style>`
`h2 {` => Selects all H2
`color:khaki;`
`}`
`body {`
`background-color: aqua;`
`}`
`</style>`
