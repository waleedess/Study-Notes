Web APIs use:
1. `POST`
2. `GET`
3. `PUT`
4. `DELETE`

# API Endpoints

> An endpoint is the specific URL a request is sent to. It points at one resource on the server, and the method tells the server what to do with it

**Endpoint Examples**:
1. `/api/v3/users`
2. `/api/updated_on`
3. `/api/state/1`
4. `/api.example.com/users/{user_id}`
